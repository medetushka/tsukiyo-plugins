# Дизайн-система Tsukiyo — как собирать макеты

Tsukiyo (月夜, «лунная ночь») — учебная платформа. Настроение: ночное небо, луна, тонкие красные линии.
Файл-источник: Karsakbayev Medet — Tsukiyo, fileKey `ASsAM4YvBYzXIcNnqAA16j`.
Страницы файла: **Design System** (мастер-компоненты, id `16:49`), **Design** (экраны, id `21:2002`), **UX Research**.

## Как устроен скилл

| Справочник | Что внутри | Когда открывать |
|---|---|---|
| references/keys.md | компоненты: node id, key, свойства и значения | пишешь скрипт сборки, вставляешь инстанс |
| references/tokens.md | переменные, текстовые и эффект-стили, сетка | красишь, ставишь отступы, текст, тени |
| references/patterns.md | шаблоны экранов, нейминг, состояния, прототип | собираешь новый экран или модуль |
| references/changelog.md | история версий | дописываешь версию |

## Платформа и тема

- Только **десктоп**: фрейм 1440 × 900 (длинные экраны — по высоте контента), сетка `Grid/Desktop 12 col` (margin 80, gutter 24).
- Только **тёмная тема**: одна мода `Night`. Светлой темы и мобилки в продукте нет — не делай их и не проси моды.
- Язык интерфейса — русский; текстовые стили проверены на казахском (ә, ғ, қ, ң, ө, ұ, ү, һ, і).

## Железные правила

1. **Сначала компоненты системы.** Всё, что есть в каталоге ниже, вставляется только инстансом (`importComponentByKeyAsync(key)` из библиотеки или `getNodeByIdAsync(id).createInstance()` внутри файла-источника). Причина: правки мастера должны доезжать до всех экранов.
2. **Не детачить инстансы.** Нет нужного состояния — скажи об этом и предложи добавить вариант в мастер; не рисуй копию.
3. **Никаких сырых значений.** Цвет — только переменные `color/*`, отступы и gap — `spacing/*`, радиусы — `radius/*`, текст — стили `Tsukiyo/*`, тени и свечение — эффект-стили `Tsukiyo/Glow/*`, `Tsukiyo/Shadow/Card`. Нужна полупрозрачность — бери готовый альфа-токен (`color/text-a60`, `color/error-a10`…), а не opacity на заливке.
4. **Примитивы (`moon/*`, `night/*`, `red/*`…) напрямую не использовать** — только через семантику `color/*`.
5. **Заголовки — Cormorant Garamond** (`Tsukiyo/Display`, `H1`–`H3`), **весь UI-текст — Inter** (`Body`, `Small`, `Caption`). Не смешивать.
6. **Одно главное действие на экран** — `Button Type=Primary`. Второе действие — `Secondary` или `Text`. Удаление/выход — `Destructive`.
7. **Ошибка поля — фирменная «трещина»**: `Input State=Error` (ломаная красная линия под полем + `Glow/Error`) + текст ошибки в helper. Не заменять обычной красной рамкой.
8. **Загрузка — луна**: `Moon/Loader` или `Button State=Loading`. Не использовать стандартные спиннеры.
9. **Форматы**: цены в тенге — `4 990 ₸` (пробел-разделитель тысяч, знак после числа); даты — `DD.MM.YYYY`.
10. **Фокус** всегда виден: `State=Focus` у Input/Button даёт `Glow/Focus`.

## Размеры

| Элемент | Размер |
|---|---|
| Button | высота 48, в формах ширина 400 |
| Input | ширина 400, высота 100 с label и helper |
| Карточка формы входа | ширина 480, фон `color/card`, радиус `radius/lg` (20), тень `Shadow/Card` |
| Course card | 312 × 338 (4 в ряд на сетке 12 колонок) |
| Modal | ширина 480 |
| Toast | ширина 380, верхний правый угол, отступ 24 |
| Header / Footer | 1440 × 72 / 1440 × 85 |

Радиусы: `radius/sm` 6 — чипы и мелкие контролы, `radius/md` 10 — поля и кнопки, `radius/lg` 20 — карточки и модалки, `radius/full` — аватары и пилюли.
Отступы: шкала 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80. Поля внутри формы — gap 16, секции — 32–48, поля страницы — 80.

## Чего в системе нет

Отдельного пака иконок нет, светлой темы нет, мобильных макетов нет, таблиц нет.
Не собирай недостающий компонент из фреймов. Скажи, чего не хватает, и предложи ближайший существующий (например, вместо таблицы — список из Lesson item).

## Порядок работы

1. Правила и каталог отсюда; шаблон экрана — references/patterns.md.
2. Ключи и id — references/keys.md; токены — references/tokens.md.
3. Сборка на странице Design: фрейм 1440, сетка, имя `Module / Screen / State`.
4. Скриншот экрана и сверка с железными правилами: нет сырых HEX/чисел, нет детачей, одна Primary-кнопка, форматы ₸ и дат.
