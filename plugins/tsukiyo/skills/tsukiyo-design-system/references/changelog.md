# Changelog

## 1.0.0 — 14.11.2026

* Первая версия скилла: правила, каталог 24 компонентов, токены, текстовые и эффект-стили, шаблоны экранов.
* Источник: файл Figma «Karsakbayev Medet — Tsukiyo».

## 1.0.1 — 14.11.2026

* Правило 11: проверять дубли имён экранов и переносить связи прототипа при замене.

## 1.0.2 — 14.11.2026

* Текстовые стили Tsukiyo/Label и Tsukiyo/Button (всего 9); бейджи переведены на Caption.

## 1.1.0 — 14.11.2026

* Мобилка: коллекция Platform (Desktop / Mobile), размеры заголовков и поля страницы меняются модой.
* Новые компоненты: Logo, Text area, Scrollbar, Pagination, Avatar, Badge, Rating, Divider, Tooltip, Achievement card, Review card, Stat card, Status bar, App bar, Tab bar, Bottom sheet, Chat button.
* Пак из 26 иконок (references/icons.md).
* Правила 12–15: иконки, логотип, мобилка, пагинация. Шаблоны мобильных экранов в patterns.md.

## 1.1.1 — 14.11.2026

* Стиль сетки Grid/Mobile 4 col.
* Нейминг мобилки: имя десктопного экрана + « · Mobile», чтобы экраны одного модуля не путались.
* Маскот Ёру — чёрная кошка, компонент Mascot с 4 настроениями.
* Empty state: маскот Ёру вместо луны (Sleeping — пусто, Sad — ничего не найдено).

## 1.2.0 — 14.11.2026

* Раздел «Как дообучать скилл»: правка пользователя → правило с причиной → подтверждение → запись → новая версия → changelog.
* references/test-prompts.md: 10 тестовых задач и общий чек-лист проверки экрана.
* Порядок работы: самопроверка по чек-листу перед ответом.

## 1.2.1 — 14.11.2026

* Illustration/Night: убраны красные линии поверх луны — луна чистая, как в оригинальной Tsukihime.
* color/crimson: только акценты (ошейник Ёру), не поверх луны.

## 1.3.0 — 14.11.2026

* Ресерч Material 3, Apple HIG, Carbon, Polaris, Atlassian, Wonder Blocks и библиотек Figma Community (Material 3 Design Kit, Simple Design System) — references/research.md.
* Правила 16–21: число пунктов Tab bar, зазор между тач-зонами, Toast по одному, тексты и места ошибок, Bottom sheet или Modal, Empty state.

## 1.3.1 — 14.11.2026

Прогон тестовых задач 4–12 на 1.3.0: 7 прошли, 2 не прошли из-за мастеров, 3 замечания к правилам.

* Button Type=Text: высота 44 (была 32 — меньше тач-зоны).
* Modal: крестик заменён на иконку Navigation / Close в зоне 44 × 44.
* Empty state: текст растягивается по ширине (на мобилке вылезал за край).
* Новый компонент Video player; шаблон Mobile lesson ссылается на него.
* Шаблон Mobile list: App bar Main для корневых экранов вкладок.
* Header: инициалы примера «АС»; правило — активный пункт навигации = текущий раздел.
* Правило 9: только вымышленные данные; настоящие имя и почта убраны с 30+ экранов.
