# Тестовые задачи для скилла Tsukiyo

Набор задач, на которых проверяют и дообучают скилл. Каждую новую версию прогоняют по всему списку. Экран считается сданным, когда выполнены общие проверки и проверки самой задачи.

Файл для тестов: `https://www.figma.com/design/ASsAM4YvBYzXIcNnqAA16j`, страница Design.

## Общие проверки (для каждого экрана)

- [ ] Все элементы из каталога — инстансы, ни одного детача.
- [ ] Ни одного сырого HEX и числа: цвета `color/*`, отступы `spacing/*` и `layout/*`, радиусы `radius/*`, текст `Tsukiyo/*`.
- [ ] Одна `Button Type=Primary` на экран.
- [ ] Заголовки Cormorant, остальной текст Inter.
- [ ] Имя фрейма по правилу, нет дубля с таким же именем.
- [ ] Цены `4 990 ₸`, даты `DD.MM.YYYY`, примеры данных без реальных людей (`student@tsukiyo.kz`).
- [ ] Мобилка: мода Platform = Mobile, сетка `Grid/Mobile 4 col`, тач-зоны ≥ 44, между ними ≥ 8.
- [ ] Ошибки: под полем или Alert над формой, текст «что случилось + как исправить».
